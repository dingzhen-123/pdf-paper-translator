pdf-paper-translator · 升级说明（2026-11-13）
============================================

这个包是「PDF 文献翻译」skill 的完整目录，解压后把 pdf-paper-translator/
整个文件夹放进 Agent 的 skills 目录即可，不需要安装到 Harness 插件体系里。

本次升级内容
------------
1. 引擎译文缓存默认启用
   原来 engine.mjs 里写死 --ignore-cache，同一份 PDF 重跑、引擎内部重试
   都要全价重翻。现在默认读缓存，需要干净重译才加 --no-cache。

2. 翻译记忆
   翻过的句子记在 ~/.pdf-paper-translator/translation-memory.jsonl，
   换文档、重跑、重试时自动复用。chat 模式下命中一次就少一轮 Agent 对话。
   可用 PDF_TRANSLATE_TM 环境变量修改保存路径。

3. 输出 PDF 瘦身
   scripts/pdf-slim.py 解决同一个引擎把每个字符画成独立文本对象、
   导致 Acrobat 打开与滚动卡死的问题，并补齐页尾未闭合的 q。
   脚本自带逐页像素回验，不通过就原样交出，最坏是什么都没优化。
   PDF_TRANSLATE_OUTPUT_SLIM=off 可关闭。

4. 记忆库容量治理
   超过 20 万条时自动压缩到 15 万条（保留最新、丢弃最老），
   避免「读取有上限、写入无上限」导致的命中率退化与体积膨胀。

与 Harness 插件安装包的区别
--------------------------
这是独立的 skill，走当前聊天模型（或 --api 指定兼容 API）翻译；
dsh-pdf-翻译插件-安装包.zip / dsh-pdf-离线资源包.zip 是 Harness 面板插件。
两者共用同一个 babeldoc 排版引擎，但代码、配置和记忆库互相独立。

参数
----
  node scripts/translate.mjs --target zh-CN --mode mono        --out ./translated-pdfs -- FILE.pdf
  --no-cache        干净重译，跳过引擎缓存与本机翻译记忆
  --api             直接用兼容 API，绕开聊天上下文
  --pages 1-3,5     指定页码
  --mode dual       原文与译文逐页交替
